NUVIA Learn: কোর্স যোগ/এডিট গাইড

নতুন কোর্স যোগ:
1. builder.html খুলুন → ফর্ম পূরণ করুন → "JSON ডাউনলোড"।
2. ফাইলটি courses ফোল্ডারে রাখুন (যেমন courses/seo-basics-1.json)।
3. courses/catalog.json-এ ফাইলের নাম যোগ করুন (ক্রম = তালিকার ক্রম):
   ["marketplace-1.json","marketplace-2.json","marketplace-3.json","seo-basics-1.json"]
4. সাইট আবার আপলোড/আপডেট করুন।

কোর্স এডিট:
1. builder.html → "বিদ্যমান কোর্স এডিট" থেকে courses/xxx.json লোড করুন।
2. বদলান → JSON ডাউনলোড → একই নামে courses ফোল্ডারে বদলে দিন → আপলোড।

নিয়ম:
- কোর্স আইডি পরে বদলাবেন না, বদলালে শিক্ষার্থীদের প্রগ্রেস হারিয়ে যাবে।
- "requires" ফিল্ডে আগের কোর্সের আইডি দিলে সেটি শেষ না হওয়া পর্যন্ত নতুন কোর্স লক থাকবে।
- builder.html আলাদা টুল, এটি শিক্ষার্থীদের হোম পেজ থেকে লিংক করা নেই।
